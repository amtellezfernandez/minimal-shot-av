# SoTA Minor Commission Slide Script

## Slide 1: A Long-Tail Simulator For Minimal-Shot Autonomy

**Visual:** `minor_spotlight_seed3/latest_rollout.svg`

The Minor submission is a randomized long-tail scenario generator. It creates
reproducible WOD-E2E-style cases and a compositional OOD layer where topology,
hazards, object novelty, conditions, and latency budgets are sampled
independently.

## Slide 2: Why Randomized Scenarios Matter

Minimal-shot autonomy should not be evaluated only on fixed scenes. A fixed map can be memorized. A useful simulator should generate structured novelty: the same class of hazard appears with different geometry, timing, visibility, and actor placement.

## Slide 3: Generator Design

The generator separates ambient scene texture from blocking hazards. Background objects make scenes visually richer, while typed hazards create the actual decision pressure. Each scenario records cluster, seed, tags, actors, map features, weather/visibility metadata, lane geometry, start, and goal.

## Slide 5: WOD-Style Evaluation Sweep

**Artifact:** `minor_eval/scenario_eval.csv`

The included sweep covers 550 runs across 11 WOD-style clusters and 50 seeds per cluster. In the generated bundle, Spotlight Reflex achieves:

- 550 / 550 benchmark passes
- 550 / 550 successful rollouts
- 0 collisions
- 0 safe stalls
- 0 near misses under the benchmark diagnostic
- 11 scenario clusters covered

## Slide 6: Compositional OOD Sweep

**Artifact:** `minor_ood_eval/scenario_eval.csv`

The stronger Minor evidence is a second 350-run sweep across WOD,
compositional, adversarial, gauntlet, and hidden suites:

- 350 / 350 successful rollouts
- 0 collisions
- 326 / 350 benchmark passes
- 36 / 60 gauntlet benchmark passes under stricter gates
- topology, hazards, object novelty, weather, visibility, surface friction, and
  latency budgets sampled independently

The gauntlet result is intentionally not perfect. It shows where the simulator
becomes hard enough to expose policy limitations.

## Slide 7: What The Metrics Capture

The evaluation records more than success/failure:

- collision
- goal reach
- final goal distance
- minimum clearance
- 5th-percentile clearance
- average progress
- average speed
- comfort cost
- intervention rate
- decision mode diversity

This makes the simulator useful for comparing policies, not just rendering nice scenes.

## Slide 8: AlpaSignal Bridge

**Artifact:** `minor_alpasignal_bridge/alpasignal_bridge_audit.json`

The Minor bundle also includes the AlpaSim/AlpaSignal bridge. The audit covers
three deterministic cases:

- static structured hazard -> simulator obstacle
- moving structured hazard -> simulator actor
- low visibility plus hard braking -> conservative caution zone

Each case returns a finite 20-point trajectory and JSON decision reasoning that
includes the signal fields used by the adapter. This keeps the submission as one
simulation stack: scenario generation, OOD stress, and an AlpaSim-compatible
trajectory-plugin bridge.

## Slide 9: Runtime Constraints

**Artifact:** `minor_runtime/minor_runtime_constraints.json`

The bundle includes a closed-loop runtime audit. It measures the actual
simulator control path: perception, world-state update, maneuver selection,
safety filtering, and rollout bookkeeping.

The audit reports hardware/Python context, process memory high-water mark, p95
step latency, p95 rollout latency, and simulator-step throughput. The pass gate
is a 50 ms p95 step budget, corresponding to a conservative 20 Hz control loop
for the abstract simulator tier.

## Slide 10: Boundaries

This is a lightweight 2D simulator, not photorealistic camera simulation. AlpaSim integration exists at a trajectory/plugin level, but full sensor-realistic perception is future work. The honest claim is randomized long-tail scenario design with reproducible closed-loop evaluation.

## Closing

The simulator is designed to make memorization hard and generalization visible. It gives a compact, reproducible way to ask whether a policy can handle new long-tail scenes rather than only replaying known examples.
