# Submission Checklist

## Required

- GitHub repo is public or ready to share privately.
- README states the problem, setup, and how to reproduce the demo.
- `models/DECLARATION.md` fully lists base models, datasets, and external services used.
- `notebooks/` contains the exploration and analysis notebook.
- `docs/two-page-writeup.md` is condensed into the final PDF or document.
- `docs/video-outline.md` has been turned into a 1-5 minute video or slide deck.
- At least one failure case is documented.
- Motivation and use of prize money are explicitly stated.

## Strongly recommended

- The README makes the architecture contribution obvious in the first screenful.
- Include latency and hardware assumptions.
- Include scenario randomization details.
- Include ablations between heuristics, prompts, and policy variants.
- Pin package versions before submission.
- Add a short evaluation table for 20-100 random seeds.
